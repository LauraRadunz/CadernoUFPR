# Cadernos de Estudo

Site estatico (sem build). Publique no GitHub Pages: Settings > Pages > Deploy from branch > main / (root).

- Progresso e erros ficam no navegador de cada pessoa (localStorage). Botoes "Salvar progresso" / "Restaurar" na tela inicial.
- Botao "Explicar com o Gemini": cada pessoa cola a propria chave (https://aistudio.google.com/apikey) no campo abaixo do botao. A chave NAO vai no codigo; fica so no navegador.
- O zip vem em 2 partes: junte as pastas (a pasta atl4/ tem as imagens das duas partes) no mesmo repositorio.
